# SIMS Manager v6.2.40 Repository Baseline

## v6.2.40の位置付け

「記事情報を更新」を、当初の設計意図どおり **Article DBで不足している記事だけをArticleID＋URLで抽出し、その記事だけを補完する方式**へ整理した版です。

- Full v6.2.40 / Starter v6.2.40-ST
- 点検対象は「記事タイトル」と「メインクエリ」の不足だけ
- 点検時はWebアクセス・GSC APIアクセスを行わない
- H1と記事タイトルの不一致比較、SEOタイトル解析、表示回数による対象分岐を点検から除外
- ArticleID列/URL列の実データ末尾を基準にArticle DBを読む
- 不足記事はArticleID＋URLで更新キュー化
- 更新開始前にArticleID＋URLの一意一致を確認
- 書込直前にArticleID＋URL＋更新前セル値を再確認
- 書込後に保存値を再読込して一致確認。不一致時は可能な範囲で更新前値へ戻す
- 6か月でもメインクエリを取得できなかった記事の完了一覧表示を維持
- 日次処理、6か月GSC取得関数、未発芽判定は変更なし
- 「1件だけ診断」はこの版ではまだ維持

最初の確認ポイントは「記事情報を更新」を開いた直後の点検時間です。点検はArticle DBの保存値確認だけなので、ここで長時間のWeb/GSC処理は発生しません。
