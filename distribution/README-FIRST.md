# SIMS Manager v6.7.45

## v6.7.45 変更点

- エース記事を日次処理で「直近28日 vs 前28日」により急落監視します。
- 日次更新直前または更新後にエースの記事を対象にし、急落当日のランク降格も取りこぼしません。
- 「順位悪化＋クリック減」または「表示急減＋クリック減」の複合条件でのみ `🚨 エース急落` と判定します。
- エース急落は通常4カテゴリの件数枠とは別に「今日の改善」へ優先追加し、aDoctor精密診断へ接続します。
- `✔️ 完了` のエースは完了後14日間を保護し、その後に急落した場合だけ90日保護を解除して `未着手 / GSC急落再評価` とします。
- 通常記事の完了保護、90日再評価、経過観察終了ルートは変更していません。

詳細は `RELEASE_NOTES_v6.7.45.md` を参照してください。
