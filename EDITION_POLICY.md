# SIMS Manager Edition Policy

Unified runtime license: STARTER, FULL, S3. FULL includes Starter features; S3 includes Full features plus S3 integration. Existing Starter restrictions remain. S3 menu requires active fresh cached S3 license; execution requires online S3 verification and existing UAT switch where applicable. Unknown edition defaults to Starter. Existing data retained on edition changes. Reload after revalidation.
