# SIMS Manager v6.6.63

## v6.6.63 変更点

- 記事管理シートを記事の現在状態を管理する唯一の正本（Single Source of Truth）に統一しました。
- 記事管理へ `作業理由` / `状態更新日` / `最終改善完了日` / `再評価予定日` を追加します。
- 作業状態は `未着手 → 今日の改善 → 改善中 → モニター中 → 完了 → 90日後に未着手` の循環を基本とします。
- 4回測定終了で再確認が必要な記事は、記事管理を `今日の改善`・作業理由 `経過観察終了` に更新してから今日の改善ビューへ表示します。
- 改善完了記事は完了日と90日後の再評価予定日を記録し、期限到来時に `未着手`・作業理由 `90日再評価` へ戻します。
- 「今日の改善」「改善の推移」は表示ビューとし、画面を開いただけでは記事管理の状態を変更しません。
- `今日の改善` を `改善中` に正規化してしまう旧正規化を修正しました。
- ArticleIDは今日の改善に可視表示したまま維持します。

詳細は `RELEASE_NOTES_v6.6.63.md` を参照してください。
