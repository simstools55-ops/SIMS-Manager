# SIMS Manager v6.2.65


## v6.2.65 変更点

- 「この記事を確認」追加時に混入したダイアログ内JavaScriptの構文エラーを修正
- 点検開始時に `loadAudit()` が実行されず「点検中…」のまま停止する回帰を解消
- `sbmArticleInfoUpdateAudit_` / `Prepare_` / `One_` / 6か月GSC取得の処理ロジックは変更なし
- 日次処理・記事ランク判定・サイト健康診断・aDoctor連携は変更なし
- Full / Starterを同期

## v6.2.63 変更点

- 「記事情報を更新」の6か月クエリ未取得結果を、未発芽へ変更／未発芽のまま／安全照合・保存確認で保留の3状態に分けて集計表示します。
- すでに未発芽だった記事は「未発芽のまま」と明示するため、未発芽へ変更0件でも処置結果が分かります。
- 6か月クエリ取得、安全照合、保存確認、日次処理のロジックは変更していません。

## v6.2.61 変更点

- v6.2.59で欠落した `sbmOpenHome` をv6.2.58正本から復旧しました。
- Home表示時に記事管理だけを軽量再集計し、記事ランク・未取得・記事改善状況を即時同期します。
- 検索露出待ちは正常な未発芽として扱い、未取得には含めません。
- 日次処理・GSC取得・ランク判定基準は変更していません。


## v6.2.58 変更点

- Home「未取得」は記事ランクの空欄ではなく、記事管理の管理フラグ「データ未取得」「要確認」を優先して集計します。
- 未取得中の記事が以前の記事ランクを保持していても、その記事はHOMEでは「未取得」へ1件だけ計上されます。
- 記事ランク7区分の合計が記事DB総数と一致するよう修正しました。
- 日次GSC取得・記事ランク判定・aDoctor連携には変更ありません。


Homeの余白を詰め、「今週のアドバイス」を今日のメッセージと同様にしっかり読める大きな表示領域へ改善しました。
日次処理・記事ランク判定・改善判定ロジックは変更していません。


## v6.2.55の位置付け

- Homeの記事ランクを「エース → 成長 → 安定 → 育成 → 発芽 → 未発芽 → 未取得」の7区分で表示し、合計を総記事数と一致させます。
- 記事改善の状況は従来どおり全記事の排他6区分で表示します。
- 改善率は右欄KPIとして維持し、算定説明コメントは削除します。
- 改善モニター内訳を「改善が確認できる」「要注意・見直し」「まだ判定できない」の3群に分けます。
- 左列は大きく改善／改善／改善傾向、中央列は変化小／要確認／見直し候補、右列は判定待ち／経過観察／再判定待ち／データ不足です。
- アドバイス欄をモニター表の直下に配置し、表示領域を広く確保します。
- v6.2.51のランク判定閾値、日次GSC取得、サイト健康診断、aDoctor連携は変更しません。
- Full v6.2.55 / Starter v6.2.55-ST

Repository root `Code.gs` がFull Editionの機能正本です。Starterは同一コードから `SBM_EDITION = 'STARTER'` のみを派生させています。
