# SIMS Manager v6.2.39 Repository Baseline

## v6.2.39の位置付け

v6.2.38で確認された「記事情報を更新」の点検遅延をコードレベルで修正した高速化版です。

- Full v6.2.39 / Starter v6.2.39-ST
- 点検時のArticle DB全27列 `getDataRange()` と全件汎用オブジェクト化を廃止
- D:Tの必要範囲だけを1回読み込み、必要な7項目だけを軽量評価
- 通常タイトル行ではSEOタイトル解析を省略
- 更新対象準備も同じ軽量読込・判定関数を使用
- v6.2.38の「6か月でもメインクエリ取得不可の記事一覧表示」は維持
- 日次処理、6か月GSC取得条件、1件診断、未発芽判定は変更なし

実運用では、まず「記事情報を更新」を開き、キャッシュ非依存の初回点検時間を確認してください。
