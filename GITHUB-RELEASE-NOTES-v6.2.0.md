# SIMS Manager v6.2.0 Release Notes

Workflow resume/recovery architecture has been consolidated.

- One user-facing unfinished-work resume entry.
- Direct aDoctor and Site Doctor continuation are routed by Case state.
- Resume mode starts at the saved treatment step; new Doctor-result intake is hidden.
- One integrity audit/repair entry replaces scattered Writer/Merge/Creator maintenance commands.
- Safe backup-based Creator Direct duplicate repair remains available from the audit dialog.
- Merge absorbed-article correction is launched from the same audit dialog.
- Semantic repairs are never guessed automatically.
