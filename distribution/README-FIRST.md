# SIMS Manager v6.7.23

## v6.7.23 変更点

- SERP参入余地チェックを `Doctor_WorkflowState` の既存チェックポイント基盤へ保存します。
- Claude依頼文生成後、SERP判定後、YELLOWからaCreatorへ進む判断後、aCreator紹介状生成後を再開ポイントとして保持します。
- 「未完了の作業を再開」に「SERP参入余地チェック」を表示し、保存済みキーワード・Claude依頼文・回答・判定・紹介状から続行できます。
- YELLOWで「今回は見送る」、または参入不可判定で終了した場合はWorkflowを完了扱いにし、未完了一覧へ残しません。
- v6.7.22までに完了した高速化・Doctor再診・既存未完了再開ロジックは変更していません。

詳細は `RELEASE_NOTES_v6.7.23.md` を参照してください。
