# SIMS Manager Starter Edition

- Version: `6.4.3-ST`
- Paste `Code.gs` in this folder into the Starter user's Apps Script project.
- This file is derived from the repository root Full canonical `Code.gs`.
- Starter and Full share canonical version `6.2.80` and the same Spreadsheet schema; Starter displays `v6.2.80-ST` to make the edition immediately identifiable.
- Starter source uses `SBM_EDITION = 'STARTER'`; Full canonical source uses `SBM_EDITION = 'FULL'`.
- Starter hides Full-only new-article, aWriter, aMerge, Creator Direct and advanced Site Doctor treatment menu routes.
- In the daily improvement navigator, Starter shows the enhanced improvement guidance and internal-link candidates but hides the aWriter prompt/feedback sections.
- Upgrade principle: replace this Starter `Code.gs` with the repository root Full `Code.gs` without rebuilding the Spreadsheet.
