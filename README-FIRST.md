# SIMS Manager v6.2.47 Repository Baseline

## v6.2.47の位置付け

v6.2.42で完成した「記事情報を更新」を固定したまま、Site Doctor健康診断へ未発芽判定を追加した版です。

- Full v6.2.47 / Starter v6.2.47-ST
- 既に記事ランクが「未発芽」の記事は健康診断で精密診断候補へ優先送付
- 健康診断で「後半90日クリック5以下」かつ「直近28日クリック0」、さらに直近28日より前に検索表示実績がある記事を未発芽として新規検出
- 新規検出時はArticleID＋正規化URL＋更新前ランクを照合してから記事ランクを「未発芽」へ変更
- ランク書込み後に保存値を再確認
- `UNGERMINATED` を精密診断候補コードへ追加し、候補順位では最優先グループとして扱う
- 健康診断書・精密診断候補画面にも未発芽を表示
- v6.2.42の「記事情報を更新」、日次処理、6か月クエリ取得ロジックは変更しない
- 「1件だけ診断」はv6.2.42で削除済み

Repository root `Code.gs` がFull Editionの機能正本です。Starterは同一コードから `SBM_EDITION = 'STARTER'` のみを派生させています。
