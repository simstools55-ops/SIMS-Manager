# SIMS Manager v6.7.29

## v6.7.29 変更点

- aDoctor経過観察終了の完了登録後に、記事管理・改善履歴・Doctor Case・Workflow・改善の推移の整合を対象案件だけ再確認します。
- 一部だけ更新された場合は成功扱いにせず、未完了として保持して確認対象を表示します。
- 完了登録時、「今日の改善」の対象行を即時に完了表示へ同期します。
- 「今日の改善」描画直前にも記事管理の作業状態を軽量照合し、モニター中／完了済み候補を除外します。
- 全シート再構築・GSC再取得・全書式再適用は追加せず、既存の高速化を維持します。

詳細は `RELEASE_NOTES_v6.7.29.md` を参照してください。
