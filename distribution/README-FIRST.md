# SIMS Manager v6.7.37

## v6.7.37 変更点

- 「未完了の作業を再開」の確認中表示を、右下toastから画面中央の待機ダイアログへ戻しました。
- 未完了案件が0件の場合、確認終了後に「未完了の作業はありません。現在、再開が必要な作業はありません。」と中央ダイアログで明示します。
- 未完了案件がある場合の既存の再開選択画面、候補探索ロジック、再開ロジック、高速化済み処理には変更を加えていません。

詳細は `RELEASE_NOTES_v6.7.37.md` を参照してください。

## 配布物管理

`distribution/` はv6.7.37以降、Repository ZIPの正式なリリース監査対象です。`Code.gs`、`appsscript.json`、配布テンプレート参照情報を毎回同期・監査します。Google Drive上のネイティブ配布テンプレートは `TEMPLATE_REFERENCE.json` で追跡します。
