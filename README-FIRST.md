# SIMS Manager v6.7.57

## v6.7.57 変更点

- 「今日の改善」が0件のときに表示される「健康診断へ進む」ボタンを、正式なサイト健康診断起動関数 `sbmDoctorRunHealthCheck` へ接続しました。
- 「健康診断を開始しています。」のまま停止する問題を修正します。
- 健康診断本体、今日の改善候補判定、状態遷移には変更ありません。

## v6.7.56 変更点

- 「aDoctor 精密診断を途中から再開」ダイアログの「対象記事」カードを、③の紹介状コピー操作の直下へ移動しました。
- 「この記事を開く」は紹介状を確認・コピーしたあとに続けて使える配置になります。
- Workflow、状態遷移、登録処理には変更ありません。

## v6.7.55 変更点

- 「✔️ 完了」なのに90日管理情報が欠落している既存記事を、日次処理で補完します。
- 補完元は最新の完了済み改善履歴にある「4回目測定日時」に限定します。
- 「最終改善完了日」は4回目測定日、「再評価予定日」はその90日後として保存します。
- 4回目測定日時を特定できない記事、既に両日付が正常な記事、完了以外の記事は変更しません。

## v6.7.54 変更点

- 日次STEP3の作業状態整合を双方向化しました。
- 有効な通常改善Workflowが残っているのに記事管理だけ「未着手」へ戻っている場合、「✏️ 改善中」へ復旧します。
- 改善の推移／改善履歴へ正式移行済みの案件は、既存の未完了整理を先に通すため復旧対象にしません。Doctor／Merge系の状態遷移は変更しません。

## v6.7.53 変更点

- 「今日の改善」の表示優先順を `🚨 急落 → 🔄 再診処置 → 通常改善候補` に固定しました。
- 再診処置を通常候補の後ろへ追加する旧同期経路が残っていても、描画直前に優先順を保証します。
- 通常カテゴリ同士の既存順序・各カテゴリの選定件数は変更しません。

## v6.7.52 変更点

- 表示テーマをモノトーン固定へ統一し、標準／モノトーンの選択メニューを廃止しました。
- Homeは生成時点でモノトーン書式を完成させ、通常のHome表示ではテーマを再適用しません。
- 旧DisplayTheme設定値は互換のため残っていても無視します。

## v6.7.51 変更点
- Homeレイアウト署名の確認位置を現在のHome配置（A16/A17/H18等）へ同期しました。
- 正常なHomeを旧レイアウトと誤判定して毎回再構築する処理を解消し、Home表示時の待ち時間と一時的な標準配色への復帰を防止します。
- Homeが存在し、バージョンとレイアウト署名が一致する場合は、再構築せず画面遷移だけを行います。


## v6.7.48 変更点

- 記事管理を作業状態の正本として整理しました。
- `🔥 今日の改善` を記事の作業状態として新規付与しない設計へ変更し、「今日の改善」シートは作業キューとして扱います。
- エース急落を `🚨 急落`、経過観察終了後の要再診を `🔄 再診処置` として記事管理へ明示保存します。
- `🛠️ 処置中` / 治療中 / 診療中は `✏️ 改善中` へ統合します。
- 旧 `🔥 今日の改善` は改善履歴を確認し、再診対象は `🔄 再診処置`、それ以外は `未着手` へ日次処理で移行します。
- 「今日の改善」は `🚨 急落` → `🔄 再診処置` → 通常カテゴリ候補の順で統合し、再診処置は既存 `EFFECT_AFTER_OBSERVATION` からaDoctor再診へ進みます。

## v6.7.46 変更点

- 「今日の改善」で改善作業を終えた行の表示を `完了` から `終了` へ変更しました。
- `終了` は「今日の改善で行う作業が終わった」ことを示し、記事管理の `👀 モニター中` や `✔️ 完了` とは区別します。
- 旧版で保存済みの `完了` 表示は互換読込し、次回の表示同期で `終了` へ統一します。
- 記事管理の `✔️ 完了`、改善履歴・改善の推移の「完了」状態は変更していません。
- v6.7.45 のエース急落監視・aDoctor導線はそのまま維持します。

詳細は `RELEASE_NOTES_v6.7.46.md` を参照してください。

## v6.7.45
- エース記事の急落監視を追加。通常カテゴリとは別枠で「今日の改善」へ追加し、aDoctor精密診断へ接続。
- 完了エースは完了後14日を保護し、その後の急落時だけ90日保護を例外解除。
