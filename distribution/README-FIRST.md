# SIMS Manager v6.7.49

詳細は `RELEASE_NOTES_v6.7.49.md` を参照してください。

## v6.7.46 変更点

- 「今日の改善」で改善作業を終えた行の表示を `完了` から `終了` へ変更しました。
- `終了` は「今日の改善で行う作業が終わった」ことを示し、記事管理の `👀 モニター中` や `✔️ 完了` とは区別します。
- 旧版で保存済みの `完了` 表示は互換読込し、次回の表示同期で `終了` へ統一します。
- 記事管理の `✔️ 完了`、改善履歴・改善の推移の「完了」状態は変更していません。
- v6.7.45 のエース急落監視・aDoctor導線はそのまま維持します。

詳細は `RELEASE_NOTES_v6.7.46.md` を参照してください。

## v6.7.45
