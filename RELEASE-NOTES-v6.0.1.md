# SIMS Manager v6.0.1

Repository Baseline update for the v6 menu UX.

## Changes

- Rename the daily-use menu from `今日の作業` to `SIMS今日の作業`.
- Put site-wide health diagnosis before article precision diagnosis.
- Flatten the Diagnosis menu so every action is available in one click.
- Flatten Settings / Maintenance so setup, repair, resume, and information actions are available in one click.
- Use separators for visual grouping because Google Sheets custom menus do not support non-clickable bold section headers.
- Preserve all existing runtime function names, Spreadsheet schema, and the Full-canonical / Starter-derived Edition policy.

This is a repository baseline update. No end-user Distribution ZIP is generated.
