# SIMS Manager v6.6.66

## v6.6.66 変更点

- 新規記事（Creator Direct）の4週間初期観察終了を、既存記事の「経過観察終了後の再診」候補から除外しました。
- 新規記事は4週観察終了後、記事管理の作業状態を「未着手」へ戻し、通常の記事評価サイクルへ移行します。
- 記事管理の「作業理由」「状態更新日」「最終改善完了日」「再評価予定日」等の内部列を、表示キャッシュに依存せず毎回非表示にします。
- 「改善の推移」は閲覧専用とし、互換用の「選択」列を毎回非表示化し、チェックボックス入力規則も除去します。
- 「今日の改善」のArticleID表示は維持します。

詳細は `RELEASE_NOTES_v6.6.66.md` を参照してください。
