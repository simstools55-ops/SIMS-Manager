# SIMS Manager v6.1.25

## Changes

- Improvement History formatting is now invalidated whenever a header/schema migration clears the sheet formatting.
- The lightweight Improvement History opener verifies that the green header style still exists before trusting its cached style-ready flag, and automatically reapplies the visible presentation when formatting was lost.
- Improvement History visible widths were rebalanced for title, ArticleID, summary, route, weekly status and final judgment columns.
- Starter Home now shows `SIMS Manager Starter Home`.
- Starter user-facing version is shortened to `v6.1.25-ST`; the canonical shared version remains `6.1.25`.
- Full remains `v6.1.25`.
