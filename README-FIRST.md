# SIMS Manager v6.2.54 Repository Baseline

## v6.2.54の位置付け

- Homeの「記事改善の状況」を未着手／今日の改善／処置中／モニター中／完了／管理対象外等の排他6区分へ変更し、合計を総記事数と一致させます。
- 記事ランクは緑系、改善管理状況は青系へ色分けし、意味の異なる指標を視覚的にも分離します。
- 改善率を改善状況表の右欄KPIへ移動し、その直下に算定上の注意書きを表示します。
- モニター内訳を「改善効果を判定できるもの」「まだ効果を判定できないもの」に分け、測定待ち系を初回測定待ち／継続観察中／再測定待ちとして表示します。
- Homeを10列へ拡張し、アドバイス欄の見切れを抑えます。

v6.2.52を基準に、記事ランク名称とHomeレイアウトを利用者向けに整理した版です。

- Full v6.2.54 / Starter v6.2.54-ST
- SEO評価順を「エース → 成長 → 安定 → 育成 → 発芽 → 未発芽」に統一
- 旧「⚠️ 低迷」は「🌱 育成」へ名称変更
- 旧「🌱 育成」は「🌿 発芽」へ名称変更
- v6.2.51の判定閾値（表示200以上またはクリック10以上で通常評価、未達でクリック3以上=発芽、0〜2=未発芽）は維持
- Home左側に6ランクを縦表示、右側に記事改善状況、その下に改善モニター中の件数・判定内訳を表示
- 改善率説明は維持
- 日次GSC取得、サイト健康診断、aDoctor連携、記事情報更新の処理方式は変更しない

Repository root `Code.gs` がFull Editionの機能正本です。Starterは同一コードから `SBM_EDITION = 'STARTER'` のみを派生させています。
