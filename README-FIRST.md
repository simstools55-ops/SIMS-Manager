# SIMS Manager v6.2.51 Repository Baseline

## v6.2.51の位置付け

v6.2.50を基準に、日次の記事ランク判定を90日集計データの「評価可能性」優先へ再構成した版です。

- Full v6.2.51 / Starter v6.2.51-ST
- 90日表示回数200以上 **または** 90日クリック10以上：既存スコアで「エース / 成長 / 安定 / 迷走（内部値: 低迷）」を判定
- 上記に届かず、90日クリック3〜9：`🌱 育成`
- 上記に届かず、90日クリック0〜2：`未発芽`
- 既存の未発芽固定処理を廃止し、日次処理ごとに同じ基準で再評価
- SearchDays=90の既存日次データを使用し、ランク判定のための追加GSC取得は行わない
- サイト健康診断の180日/90日/28日による精密な未発芽診断は維持
- エース / 成長 / 安定 / 低迷の既存スコア閾値は変更しない

Repository root `Code.gs` がFull Editionの機能正本です。Starterは同一コードから `SBM_EDITION = 'STARTER'` のみを派生させています。
