# SIMS Manager v6.7.50

## v6.7.50 変更点
- Homeレイアウト署名の確認位置を現在のHome配置（A16/A17/H18等）へ同期しました。
- 正常なHomeを旧レイアウトと誤判定して毎回再構築する処理を解消し、Home表示時の待ち時間と一時的な標準配色への復帰を防止します。
- Homeが存在し、バージョンとレイアウト署名が一致する場合は、再構築せず画面遷移だけを行います。


## v6.7.48 変更点

- 記事管理を作業状態の正本として整理しました。
- `🔥 今日の改善` を記事の作業状態として新規付与しない設計へ変更し、「今日の改善」シートは作業キューとして扱います。
- エース急落を `🚨 急落`、経過観察終了後の要再診を `🔄 再診処置` として記事管理へ明示保存します。
- `🛠️ 処置中` / 治療中 / 診療中は `✏️ 改善中` へ統合します。
- 旧 `🔥 今日の改善` は改善履歴を確認し、再診対象は `🔄 再診処置`、それ以外は `未着手` へ日次処理で移行します。
- 「今日の改善」は `🚨 急落` → `🔄 再診処置` → 通常カテゴリ候補の順で統合し、再診処置は既存 `EFFECT_AFTER_OBSERVATION` からaDoctor再診へ進みます。

## v6.7.46 変更点

- 「今日の改善」で改善作業を終えた行の表示を `完了` から `終了` へ変更しました。
- `終了` は「今日の改善で行う作業が終わった」ことを示し、記事管理の `👀 モニター中` や `✔️ 完了` とは区別します。
- 旧版で保存済みの `完了` 表示は互換読込し、次回の表示同期で `終了` へ統一します。
- 記事管理の `✔️ 完了`、改善履歴・改善の推移の「完了」状態は変更していません。
- v6.7.45 のエース急落監視・aDoctor導線はそのまま維持します。

詳細は `RELEASE_NOTES_v6.7.46.md` を参照してください。

## v6.7.45
- エース記事の急落監視を追加。通常カテゴリとは別枠で「今日の改善」へ追加し、aDoctor精密診断へ接続。
- 完了エースは完了後14日を保護し、その後の急落時だけ90日保護を例外解除。
