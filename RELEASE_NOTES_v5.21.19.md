# SIMS Manager v5.21.19-dev

- Top menus reorganized by user intent: 今日の改善 / 改善の進捗 / サイト全体の診断 / 記事一覧.
- Individual article actions are consolidated under 記事一覧: 詳細 / 診断・改善 / 改善履歴.
- Article-list sorting menu removed; Google Sheets header filter is automatically enabled when the article list is opened.
- 詳細設定 is hidden from 設定・メンテナンス.
- Initial article-information supplementation batch is standardized at 150 articles. Sites with more than 150 remaining articles continue through the existing continuation dialog.
