# SIMS Manager v6.5.9

## v6.5.9 変更点

- 改善ナビのクライアントJavaScript構文エラーを修正しました。
- v6.5.6で追加した改善ガイド表示のHTML属性引用符が、生成後の`<script>`内で文字列を途中終了させ、ダイアログは表示されてもクエリ・本文取得が起動しない状態になっていました。
- 改善ガイドHTMLの生成方法を修正し、生成後のクライアントJavaScript自体を構文検査する回帰テストを追加しました。
- aWriter依頼文、Search Consoleクエリ取得、本文取得、内部リンク候補判定のロジックは変更していません。

## v6.5.7 変更点

- 改善ナビの最新クエリ取得を高速化し、SearchConsole_Data全件走査を避けて対象URLの必要行を優先取得します。
- Search Console APIのURL候補照会を逐次処理から並列処理へ変更し、候補の優先順位と採用結果は従来どおり維持します。
- 内部リンク候補生成では記事DB・SearchConsole_Dataの必要列だけを読み込み、不要な全列取得を削減します。
- クエリ取得時の記事情報を後段へ引き継ぎ、同一記事の再検索を減らします。
- aWriter依頼文生成、aWriter Contract v4.2、改善判定ロジックは変更していません。

## v6.5.6 変更点

- 改善ガイドの3件固定を廃止し、aWriterと同じ改善スコープに基づいて必要な改善内容をすべて利用者向けに表示します。
- 「なぜ：」「どこを：」「どうする：」「完了の目安：」を太字小見出し＋改行で表示します。
- Full Editionでは内部リンク候補も初期状態で折りたたみ、説明文の下の「内部リンク候補を開く」ボタンで展開します。Starter Editionは初期表示を維持します。
- aWriter依頼文生成とaWriter Contract v4.2は変更していません。

## v6.5.5 変更点

- 改善ナビの従来のP0・P1・P2形式の改善ポイントを、利用者向け「自分で修正する場合の改善ガイド」へ刷新しました。
- Full EditionはaWriter依頼文を主導線のまま維持し、改善ガイドを必要時だけ展開します。Starter Editionは改善ガイドを初期表示します。
- aWriter依頼文生成ロジックとaWriter Contract v4.2は変更していません。

## v6.5.4 変更点

- 日次処理を含むダイアログを総点検し、Apps Scriptのウィンドウタイトルと本文先頭見出しが同じ場合に二重表示される問題を共通表示関数で解消しました。
- 完全一致する先頭見出しだけを自動除去し、完了・警告・結果など意味の異なる本文見出しは維持します。
- Full / Starterの両Editionへ同じ修正を反映しました。

## v6.5.3 変更点

- 高評価記事の改善登録時に、タイトル・SEOタイトル・メタディスクリプション・メインクエリと変更箇所のBefore/Afterを改善前スナップショットとして保持します。
- 28日後のaDoctor再診にはスナップショットをEvidenceとして渡し、KEEP（維持）・IMPROVE（再改善）・RESTORE（原状復帰）の判断を要求します。
- RESTORE判定時はSIMSが復元パッケージを提示し、利用者がブログ側へ手動反映後に完了登録すると、新しい7日目・14日目・21日目・28日目の再観察を開始します。
- 「今日の改善」の区分列を折り返し表示し、「収益改善（流入）」が見切れにくい表示へ改善します。

## v6.2.80 変更点

## v6.2.71 変更点

- カニバリ精密診断では競合する自サイト記事の本文と180日GSC Evidenceを自動収集し、同一Caseの再診依頼JSONを生成します。
- 追加診断結果は同じaDoctorダイアログから続けて登録できます。
- 記事詳細ダイアログの内側に重複表示されていた「選択記事の詳細」見出しを削除しました。
- 日次GSC取得、14日ゲート、記事ランク判定、完成済みの記事情報更新は変更していません。
