# SIMS Manager v6.1.38 Repository Baseline

## v6.1.38の位置付け

v6.1.35で追加したSheets日付シリアル変換を、実際の「改善の推移を開く」経路から確実に起動できるようにした修正版です。

- 改善の推移を開く時に既知の日付破損を軽量検出
- 異常時のみ改善履歴の日付を冪等修復
- 異常時のみ改善の推移を軽量再生成
- 正常時は従来どおり閲覧専用の高速経路
- Full v6.1.38 / Starter v6.1.38-ST
