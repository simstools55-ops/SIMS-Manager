# SIMS Manager v6.7.38

## v6.7.38 変更点

- 日次処理後の「今日の改善」を最新状態へ整合し、前日までに完了した記事や現在進行中の記事を表示対象から除外します。
- 空いた枠は、既存の候補選定ルールで選べる記事がある範囲だけ補充します。候補が不足する場合は無理に埋めません。
- 経過観察終了案件の既存フロー、候補カテゴリ・優先順位・件数上限、高速化済み処理は維持します。

詳細は `RELEASE_NOTES_v6.7.38.md` を参照してください。

## distribution 管理

`distribution/` はv6.7.37以降、Repository ZIPの正式なリリース監査対象です。`Code.gs`、`appsscript.json`、配布テンプレート参照情報を毎回同期・監査します。Google Drive上のネイティブ配布テンプレートは `TEMPLATE_REFERENCE.json` で追跡します。
