# SIMS Manager v9.2.3 — はじめに

## Apps Scriptへ適用するファイル
`apps-script/Code.gs` が唯一の実行コード正本です。Apps Scriptエディタの `Code.gs` を更新する場合、このファイルを使用してください。

本ZIPのフォルダー整理は**パッケージ構成のみの変更**です。実行コードは従来のv9.2.3とバイト単位で同一です。

## v9.2.3の変更
既存バックアップ保存先にブログURLが登録されている場合、設定上のBlogUrlが空欄になっても安全停止します。既存の保存先引き継ぎ・フォルダー階層検証・バックアップ作成方式は維持しています。

## 試験状態
v9.2.2で通常のTESTバックアップ作成と構造検証は実機PASS。v9.2.3の実機試験、識別不一致時の停止、復元失敗時のロールバックは未検証です。運用環境への適用前に現行版を保管してください。
