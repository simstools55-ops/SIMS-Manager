# SIMS Manager v6.2.49 Repository Baseline

## v6.2.49の位置付け

v6.2.47の健康診断UI修正を基準に、未発芽のHome可視化と利用者向け説明を追加した軽微改善版です。

- Full v6.2.49 / Starter v6.2.49-ST
- Home「記事ランクのまとめ」に「🌰 未発芽」の件数と前回比矢印を表示
- Homeの改善率について、効果測定完了記事だけを分母にすることを利用者向けに説明
- 「診断」配下に「サイト健康診断」サブメニューを設け、「サイト健康診断を実施」「サイト健康診断結果を開く」を配置
- 健康診断所見の複数指摘を「。また、」で自然につなぐ
- 未発芽判定条件、aDoctor連携、記事情報更新、日次処理ロジックは変更しない

Repository root `Code.gs` がFull Editionの機能正本です。Starterは同一コードから `SBM_EDITION = 'STARTER'` のみを派生させています。
